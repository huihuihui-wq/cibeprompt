/ 01 · Camera Movement Dictionary

10 movements, 10 emotions

Every movement is quantified: height, distance, angle, speed.
Copy-paste into any AI video platform.

Dolly In

Push In

Emphasize subject, reveal details, build tension

"Slowly push in from wide shot to close-up, ten centimeters per second"

Dolly Out

Pull Back

Reveal environment, loneliness, ending

"Pull back from close-up to wide shot, revealing city skyline"

Tracking

Truck

Follow movement, show space, maintain rhythm

"Track parallel to subject, two meters per second, one point five meter distance"

Follow Shot

POV

Immersion, subjective POV, continuous motion

"Follow from behind, handheld breathing, one meter distance"

Orbit

Arc Shot

360 showcase, emphasize subject, create vertigo

"Orbit one hundred eighty degrees around subject, medium shot, uniform speed"

Crane

Boom

Perspective shift, spatial reveal, emotional rise

"Crane up from ground to three meters, angle shifts horizontal to vertical"

Handheld

Breathing

Realism, breathing feel, documentary texture

"Slight shake, five degree amplitude, handheld breathing feel"

Aerial

Drone

Grand scale, spatial layers, god's-eye view

"Aerial view at fifty meters, slowly descending, city panorama"

Whip Pan

Snap

Speed impact, transition, kinetic energy

"Whip pan rapidly, image blurs into color streaks, decelerates to clarity"

Rack Focus

Focus Pull

Narrative shift, attention guidance, depth play

"Foreground letter sharp, background figure blurred, focus slowly shifts"

/ 05 · Installation

3 steps to install

No Node.js. No Python. No build tools.

1

Install OpenCode

If you don't have it, visit opencode.ai.

# Mac/Linux
curl -fsSL https://opencode.ai/install | bash

# Windows (PowerShell)
irm https://opencode.ai/install | iex
2

Tell OpenCode one sentence

In OpenCode TUI, send:

Install CinePrompt skill by following
https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/INSTALL.md

OpenCode auto-fetches the install guide and executes it.

3

Or run the one-liner

# Mac/Linux
curl -fsSL https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/install.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/install.ps1 | iex

Restart OpenCode TUI and use /cine.

/ 06 · Other AI Tools

Works with Claude Code, Cursor, and more

CinePrompt is a portable skill — install it into any compatible AI coding tool.

C

Claude Code

recommended

One-liner install into ~/.claude/skills/cibeprompt/:

# Mac/Linux
mkdir -p ~/.claude/skills/cibeprompt && \
curl -fsSL -o ~/.claude/skills/cibeprompt/SKILL.md \
  https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/skills/cibeprompt/SKILL.md

# Windows (PowerShell)
$base = Join-Path $env:USERPROFILE '.claude\skills\cibeprompt'
New-Item -ItemType Directory -Path $base -Force | Out-Null
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/skills/cibeprompt/SKILL.md' `
  -OutFile (Join-Path $base 'SKILL.md') -UseBasicParsing

Then in Claude Code, the skill auto-loads when the prompt matches.

C

Cursor

Download the SKILL.md body as your .cursorrules file:

curl -fsSL -o .cursorrules \
  https://raw.githubusercontent.com/huihuihui-wq/cibeprompt/main/SKILL.md

# Then restart Cursor to load the rules
